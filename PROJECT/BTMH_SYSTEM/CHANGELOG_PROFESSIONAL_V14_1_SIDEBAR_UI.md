# CampusFace V14.1 - Sidebar Icon Clarity

UI-only refinement built on V14 Offline Core Reliability + Action Engine.

- Replaced mixed text-symbol navigation icons with a consistent local inline-SVG set.
- Increased icon size and contrast on the dark sidebar.
- Added balanced 30px icon containers with restrained teal highlighting.
- Active and hover states are clearer without adding heavy animation.
- Normalized icon/text alignment, gap and item height.
- Added a shorter-screen density adjustment so the larger icons do not make laptop navigation unnecessarily tall.
- No FaceID, camera, PTZ, Action AI, offline, database, duplicate-guard or attendance logic changed.
